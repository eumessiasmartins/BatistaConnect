# BatistaConnect

Crie uma plataforma de comunicação interna para empresas. 
o módulo timeline deve ter a opção de: Postagem, Comunicado, Evento, Enquete.
Pode ser enviado arquivos de imagem e arquivos de documento.

Se escolher Postagem, segue uma postagem apenas de arquivos de imagens.
Se escolher Comunicado pode enviar arquivos de imagem e arquivos de documentos. colocar também uma opção de Confirmação de Leitura.
Se escolher Evento, Colocar Nome do Evento, Data, hora de inicio e hora de término, formato com opção de Local e Online,  se escolher local, digitar o local, se escolher online digitar o link. POder colocar uma imagem.
Se escolher Enquete, providenciar os dados para para um enquete.

Deve ter a opção de curtir e comentar a publicação.

O design da pagina deve ser elegante e suave com cores em tonalidade azul pastel. 

Criar um módulo de configurações:
Permitir Cadastrar os dados da empresa.
Módulo de Permissões e módulo de colaboradores.
